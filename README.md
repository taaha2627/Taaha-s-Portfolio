# Taaha Creative Portfolio — Cinematic Edition

A React + Vite personal portfolio with a Netflix-inspired profile-selection intro, cinematic black/burgundy styling, animated interactions, and responsive project cards.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Main files

- `src/main.jsx` — intro/profile selection and portfolio sections/interactions.
- `src/styles.css` — cinematic theme, intro screen, layouts, responsive styles.
- `public/profile.png` — professional portrait.
- `public/Taaha_Tahseem_Resume.pdf` — résumé preview/download.
- `.github/workflows/deploy.yml` — GitHub Pages workflow.

The intro cards are visual entry points to the same portfolio, not separate user accounts. The contact form currently opens the visitor's email app with a prefilled message; it does not submit to a backend.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/taaha2627/taaha-portfolio.git
```

Navigate into the project:

```bash
cd taaha-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
